# Synthetic dashboard

Surface: `dashboards/model-demo.html`. Mode: Operate/Read. This is a synthetic export of the existing employee-model dashboard, preserving the chart-first layout and native selectors.

Use a system sans serif, restrained neutral light/dark surfaces and blue as the reference-series color. Separate sections with whitespace and fine neutral rules. Put employee selection beside the model controls; stack charts and controls on phones. Keep quantity/unit axis labels, touch-accessible detail inspection and visible no-data/training states. A small fixed type scale and readable 12 px SVG labels serve the statistical content.

The data declaration and uncalibrated interpretation remain visible. No promotional claims, decorative imagery, dashboards implying independently verified fraud, or copied private records. The primary interaction changes the selected synthetic employee; the temporal controls compare precomputed scenarios while showing how predictions depend on assumptions.
